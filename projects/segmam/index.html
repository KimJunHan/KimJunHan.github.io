SegMam

Multi-Scale Deformable Cross-Mamba Attention with Pseudo-LiDAR from Multi-Camera Depth for BEV Segmentation

First author 2025 — 2026 IEEE Access (SCIE)

Overview

SegMam tackles a key limitation of Transformer-based BEV segmentation: the quadratic cost of cross-attention between image features and BEV queries. By reformulating cross-attention as Mamba's selective scan, the model achieves linear complexity while preserving the ability to attend to spatially relevant features.

A distinctive design choice is the complete elimination of real LiDAR or radar input. Instead, pseudo-LiDAR point clouds derived from monocular depth estimation serve as the value stream in a Query–Value two-stream architecture, with no explicit Key projection required.

Approach

The architecture introduces a Query–Value two-stream block built on Mamba's selective state-space mechanism:

  • BEV queries (Q stream)
  • Pseudo-LiDAR values (V stream)
  • No Key projection
  • Multi-scale deformable sampling
  • Selective scan (Mamba)
  • Camera-only input

Multi-camera images are processed through a backbone to extract multi-scale features. Monocular depth estimation generates pseudo-LiDAR point clouds that are projected into BEV space. The Cross-Mamba block then selectively scans and fuses these representations with learned BEV queries to produce the final segmentation map.

Results

The most notable improvements appear in challenging conditions — night (+13.6 mAP IoU) and rain (+6.0) — demonstrating that the pseudo-LiDAR representation provides robustness in degraded visual conditions where pure image features struggle.

Code and checkpoints have been publicly released.
