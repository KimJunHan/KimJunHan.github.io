Vehicle Data Pipeline

End-to-end data collection platform and ROS perception module for multi-institution autonomous driving project

National project (RS-2024-00445826) 2024 — present KEIT funded

Overview

This national R&D project required converting a Hyundai Sonata into a full data collection platform and building a perception module whose output feeds directly into a planning stack shared across four institutions.

My responsibilities spanned the full pipeline: sensor setup, data collection, polygon ground-truth labeling for drivable area, model training and evaluation, ROS integration, and interface coordination with partner teams. The system was validated through a certified evaluation at KIAPI.

Platform specifications

Sensors

  • 6× surround-view cameras
  • 1× LiDAR
  • GPS/RTK positioning
  • IMU (inertial measurement)

Output interface

  • nav_msgs/OccupancyGrid — ROS message type
  • 0.3 m cell resolution
  • 200 × 120 grid cells
  • 10 Hz publication rate

Data

  • 119 labeled scenes
  • Polygon ground-truth annotation
  • Ego-centric BEV drivable area
