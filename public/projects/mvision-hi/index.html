Overview

M.VISION HI is Hyundai Mobis' autonomous robotaxi concept vehicle, showcased at CES. The vehicle demonstrates future mobility with advanced in-cabin AI and autonomous driving capabilities.

As an AI/Vision developer at Anyractive, I was responsible for developing real-time vision algorithms for the vehicle's intelligent interaction systems, integrated across a multi-PC architecture.

My Contributions

  • Gaze Tracking System
  • Gesture Recognition
  • In-Cabin Camera Pipeline
  • Multi-PC Real-Time Integration
  • Python / C++ / OpenCV

Developed real-time gaze tracking and gesture recognition algorithms for in-cabin passenger interaction. The system operated across a distributed architecture spanning multiple PCs, requiring careful synchronization and latency optimization.
