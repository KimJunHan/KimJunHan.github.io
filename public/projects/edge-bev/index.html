Real-time BEV on Edge

Lightweight BEV drivable area perception optimized for NVIDIA Jetson edge devices via ONNX export and TensorRT acceleration

Co-author 2025 — 2026 KSAE Spring Conference

Overview

Research models that report impressive accuracy on desktop GPUs often cannot run within the latency budget of an actual vehicle. This project bridges the gap between lab accuracy and on-road deployment by taking a BEV segmentation model through the full optimization pipeline to NVIDIA Jetson boards.

The goal was not just to demonstrate that deployment is possible, but to systematically measure where latency is spent and how much accuracy is traded at each optimization step.

Optimization pipeline

PyTorch model → ONNX export → FP16 quantization → TensorRT engine → Jetson deployment

The model was exported to ONNX with static input shapes, then quantized to FP16 precision. TensorRT performed layer fusion, kernel auto-tuning, and memory planning specific to each Jetson board's GPU architecture.

Measurements confirmed that the same model code differs by a factor of two in latency across Jetson board generations, emphasizing the importance of board-specific profiling rather than relying on theoretical FLOP counts.

Results

IoU retained
~72%
AGX Orin latency
44 ms
AGX Thor latency
22 ms
Baseline latency
352 ms

The optimized model achieves an 8× speedup on AGX Orin (352 ms → 44 ms) and a 16× speedup on AGX Thor (352 ms → 22 ms), while retaining approximately 72% IoU — well within the operational requirements for real-time drivable area perception.
